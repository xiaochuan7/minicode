# 唯一的测试缝是动作执行缝，决策层不进单测

本项目只有**一条**测试缝，称为**动作执行缝**：输入是目标描述、一帧截图与可选的控件树快照，输出是动作、最终落点与意图；缝以下的抓屏、DPI 感知、输入注入、控件树查询、模型调用全部由假实现替身。理由：这是唯一一条既不打真桌面、不花钱，又能覆盖标定唯一性、裁剪源、裁剪门控、控件树脱敏这四条红线的缝——它们全部落在感知到执行的范围内。

## Considered Options

- **任务级缝**（输入一个任务、输出一串动作）：决策层也进缝，就必须把模型与整个循环一起假造——那是在测假模型而不是测系统，还要额外维护一套假循环与假重试。
- **更低的缝**（只测定位）：缝更窄，但决策层与校验层基本测不到。

## Consequences

- **决策层（L3）没有单测覆盖**，这是明确承担的分工而非遗漏：单测负责感知到校验各层的确定性行为，端到端评测负责全链路，并承担规划质量、跨应用流程、失败恢复的真实表现。
- 缝上只断言对外可见的契约字段，不断言内部算法。
- 定位过程产生的追踪记录走可注入的旁路出口，不进主返回类型——它是观测数据而非控制流数据，这样将来更换定位后端时上层调用方不用改。
