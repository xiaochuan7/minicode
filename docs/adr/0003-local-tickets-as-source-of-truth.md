# 工单真值来源是本地文件，GitHub Issue 是联网后的镜像

每一张工单的**权威副本**落在仓库内的本地工单文件里；GitHub Issue 是网络可达之后与之对应的镜像。理由：这台机器经常连不上 GitHub（没有 VPN），若以 Issue 为唯一权威，离线期产出的工单既落不了地、也活不过一次会话；若以本地文件为权威，联网后可以一次性同步出去。

这与"议题跟踪器选 GitHub Issues"并不冲突：跟踪器决定工作**在哪里被组织与流转**，真值来源决定工单内容**以哪一份为准**。

## Consequences

- 离线期可以开工、能跨会话存活；恢复网络后把工单镜像回议题跟踪器。
- 镜像与权威副本出现分歧时，以本地副本为准，并重新同步。
