## 一、一句话结论

**这一轮把三个东西搬到了生产档，但「头条分数」这条验收线判不了 —— 因为本轮量到了跨跑批噪声的量级。**

1. **生产档 1536×960 → 2016×1260**（T2）**落地**（探针透传、标定逐尺寸对齐、坐标契约未变）。
2. **精定位 crop 放大**（T3）**机制落地，但效果不成立**：放大倍数按**粗框**推目标尺寸，
   粗框常偏大 ⇒ 58 条里只有 **16 条**真放大（倍数中位 1.0）⇒ icon 表观中位只到 **28.0 px**（<30 px 的目标线）；
   **同 60 条真配对：命中率 −1 条（p=0.6875）** ⇒ **无效应**。
   顺手修掉一个**既有链路**的潜在 bug（超宽屏的 1:1 crop 是 2560 px > 服务端上限）。
3. **多候选 + 标记图选择 + 整屏再搜**（T4）**机制落地，但效果是负的**：
   同 60 条真配对 **−4 条（−6.67 pp，p=0.1797）**；**假命中 5 → 6 没有降**；
   **整屏再搜一次都没触发**（标记图上模型一次都没答 0，60 条里 39 条编号读不出来）。
4. **护栏两条候选都不采纳**（T5，第一步判定门就否掉了：候选 A **净 −41 条**）。
5. **端到端 wave1 从 0/5 → 3/5**（主口径 60%）：**浏览器三票 C-1/C-2/C-3 全通过**
   （上一轮是「未登录 → SKIP」，本轮 **infeasible 从 3 降到 0**）。
6. **wave2 主口径 3/9 = 33.3%（未达 ≥5/7）**：通过数与上一轮相同（3），但分母从 7 涨到 9。
7. **但**：同配置（2016 档、不放大、一次一问）**同批 183 条重跑一遍是 59.02%**，
   而上一轮同一配置报的是 **64.48%** —— **Δ −10 条（−5.46 pp），mid-p p = 0.0989，CI 跨 0**。
   ⇒ **上一轮的 64.48% 不可复现**；在 n=183 上，「单次跑批的绝对分」判不出 ±10 条的差。
   **本轮的所有「A vs B」的结论都必须按这个噪声底噪读。**

## 四、头条成绩（带 Wilson CI、配对 p 与 CI、分层）

### ① 跨跑批噪声的量级（本轮最重要的一个数）

**同一个配置**（2016×1260 档、`variants=1`、不放大、一次一问、同 183 条、同判定口径），
**上一轮的跑批 vs 本轮的跑批**：

| | 上一轮 `runs/g3-eval-2016` | 本轮 `runs/v2-eval-2016-control` |
|---|---:|---:|
| always 命中 | **118/183 = 64.48%** | **108/183 = 59.02%** |

* 配对 McNemar（同一批 183 条按 `sample_id` 对齐）：**左（上一轮）独赢 23 / 右（本轮）独赢 13**（不一致 36 对）
  → **Δ = −10 条 = −5.46 pp**，**95% CI [−12.02, +1.09] pp**（配对 bootstrap），
  **mid-p p = 0.0989** / 精确二项 p = 0.1325 / χ²+CC p = 0.1336 → **CI 跨 0**。
* 分层：icon **38 → 41**（Δ +3.45 pp，p=0.5235）；text **80 → 67**（Δ −13.54 pp，**p=0.0005**）。
* 标定逐尺寸**完全一致**（scale / 声明尺寸 / token 断言全同，只有 `rounds` 5 → 21）
  ⇒ **不是档位或标定变了，是模型重抽**。

⇒ **结论**：在 n=183 上，**「同一配置的两次独立跑批」差 10 条是常态**（本轮实测）。
**本轮任何「A vs B」的差，只要 |Δ| ≲ 10 条，就不能当效应读。**
这直接印证了方案 §8.2 第 2 条（「2016 档的 +8.7 pp 里混着模型重抽噪声」），
也说明**「≥70%」这条线在单次跑批上不可判**。

### ② 本轮对照臂（2016 档，183 条）的分层与区间

* always **108/183 = 59.02%**，Wilson 95% CI **[51.78%, 65.89%]**
* coarse_only **79/183 = 43.17%**（Wilson [36.21%, 50.41%]）
* icon **41/87 = 47.13%**（Wilson [36.98%, 57.51%]）｜text **67/96 = 69.79%**（Wilson [59.99%, 78.07%]）
* telemetry：`crop_opened` 175、`crop_contains_target_rate` **85.14%**、
  `fake_hits` **20**、`fallback_cause_distribution` `{"no_output": 12}`、
