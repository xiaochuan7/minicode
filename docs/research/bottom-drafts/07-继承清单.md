## 6. 一句话总结

**§7 现在漏掉的不是"几条继承"，而是三样东西：**

1. **UIA 原文脱敏**（安全）—— 你明确打算把 UIA 树 dump 进 LLM 上下文，而 czdcode 实测捞到过草稿里的 API key；你的六份底稿对此实质覆盖为 0。**这是唯一一条"不加就可能出事"的项。**
2. **测量契约**（三段耗时 + 三类失败）—— 你的方案全部围绕速度与成本，但没有一处规定怎么测量；没有它，§6 里程碑的验收标准出了问题你无法归因。
3. **UIA 工程细节与中文桌面应用实测** —— 39 项控件类型表、12 类可交互白名单、作用面打分规则、微信门控的四种解锁手段、Qt 启动期重试规则；你的底稿在 Python 生态侧齐全，**中文桌面应用侧是空白**。

**对 §7 的最大异议**：继承 #1「模型永不碰坐标」在你的方案里**只对 UIA 通道成立**，而 §7 的措辞与结论仍按"结构性免疫"在写 —— 这会让后来人以为视觉通道也免疫，从而低估 §1.4 标定的承重。**建议把 §7 继承 #1 与 §1.4 标定直接绑定**（标定失败 = 视觉通道不可用），而不是让两者各自独立。

**对丢弃 #1 的修正**：丢 Java 代码对，但请把 **A7 / A23 / COM 生命周期 / GUID 端序 / BSTR 释放 / 槽位顺序** 这六项单列为「继承知识，不抄代码」——**它们在 Python 生态没有现成中文排错文档，且每一个的症状都是静默的**（RECT 写错 → 所有 bbox 变 0；GUID 端序写错 → `REGDB_E_CLASSNOTREG`；Release 次数错 → JVM 在没有 Java 栈帧的地方崩）。
