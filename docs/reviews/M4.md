## 3. 与工单假设不符的现实（**八条**）

1. **端口形状不许变 vs 消歧必须送画面** —— `LocateRequest` / `PointerRequest` 都得带上那一帧，
   否则模型看不到「哪个是哪个」。本轮**只加字段、给默认值**（既有实现照旧能用），
   没改任何既有字段的含义（协议版本口径：只增不改不升版本）。
2. **脱敏没上线原本报的是「选择失败」** —— 那是**假话**（模型压根没被问）。
   按工单 M4 AC 7 改成**明确拒绝启用**（新错误码 `channel_disabled`），
   M3 的那条单测随之改了断言。
3. **M3 的重定位靠「身份 + 位置重叠」，与 AC 8「控件移动过也要用新框」互斥** ——
   本轮改成**身份族 + 离原位置最近**：族里个数变了（控件没了 / 多了一个同名）→ 认不准 → 拒绝动作。
   ⚠️ **残留的固有歧义**：同名同型且**没有 AutomationId** 的控件被「换掉」时，
   移动与替换在信息上不可分（本轮按 AC 8 选了「移动 → 用新框」这一侧）；
   有 AutomationId 的控件不受影响（身份里含它，族内唯一）。
4. **帧的像素排布不是固定的** —— 抓屏后端有 numpy 时给 **BGR**（3 字节/像素），
   没有 numpy 时给 **BGRA**（4 字节/像素）；编 PNG 前必须分清，否则颜色是反的
   （`CapturedFrame.pixel_format`）。
5. **「名称匹配不上」在架构备忘里与 coverage failure 的定义互斥**（两处字面打架）：
   实现按**候选集空不空**判（空 = 覆盖失败），并已把这条口径写进
   `docs/spec.md`（§8 与 §11 各一条注）、架构决策备忘 §2.5 ① 与 ADR-0004，文档与实现不再互斥。
6. **回显口径原先只写了坐标** —— 架构备忘 §3 与规格 §7 都写「每步回显模型自己发出的**坐标**」，
   但 UIA 通道的消歧模型不产坐标。已把两处改成「模型发出的内容（坐标或选中项）+ 实际发送尺寸」，
   并写明「UIA 通道不许伪造成坐标回显」。
7. **模型调用的 token 预算不能太小** —— 第一次真机跑（`max_tokens=512`）直接吃了
   **坑③**：「HTTP 200 但本次没有文本输出（思考链把预算吃光）」。
   预算已提到 **2000**（与模型客户端同一个默认值）；另外**模型侧失败不再抛穿整条链路** ——
   通道把它变成**选择失败**（模型侧错误如实写进消息、请求日志也记一条），**零动作下发**。
8. **真机上「同名候选」可能落在别的窗口底下** —— 第一次跑时模型选中的面包屑项正好被
   另一个窗口压住，缝的**遮挡判定**（M0 的老逻辑）先拒绝执行，报「目标窗口置前失败」，
   动作没下发。这是既有行为，本轮只把它记下来（换个不被压住的位置再跑就通了）。
