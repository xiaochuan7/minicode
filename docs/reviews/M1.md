## 3. 与工单假设不符的两处现实

### 3.1 坑① 的「HTTP 1010」是**错误编号**，不是状态码

- 实测：去掉 `user-agent` → **HTTP 403**，响应体
  `{"type":"…/cloudflare-1xxx-errors/error-1010/","title":"Error 1010: Access denied","status":403,…}`。
- 即「1010」是 Cloudflare 的**错误编号**，HTTP 状态码是 403。工单与 `docs/01-现状.md` §2 都写成「返回 HTTP 1010」。
- 回归的判据已按**错误编号 1010** 认（`regressions.py:149-161`），不再按状态码认。

### 3.2 `x-opencode-client` **当前不再被强制**

- 实测：只去掉 `x-opencode-client`（保留 `user-agent`）→ **HTTP 200，正常出文本**。
- 为什么以前没发现：首轮测量（`src/minicode/verify/test_00_endpoint_matrix.py`）的四组 UA 里，
  带 `opencode/1.0.0` 的那一组**两个头一直一起带**，**从没单独测过「只留 user-agent」**；
  「两个头都必须」是一次**推断**，不是一次测量。
- 客户端仍然**两个头都发**（照旧带上，换网关时不丢），但「必需」这个理由已不成立。
- 已把复测结论写回 `docs/01-现状.md` §2 坑 1（含对照表）与 `docs/00-现状.md` §6.2。

> **需要人拍板吗？** 需要**一处措辞拍板**（不影响代码）：M1 工单 AC 2 与 `docs/01-现状.md` 的
> 「两个头都必须 / 返回 HTTP 1010」要不要按实测改写。本轮**没有**擅自改工单（工单是真值来源，改写属口径决定）。
