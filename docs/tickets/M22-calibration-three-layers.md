## What to build

把标定与视觉通道准入拆成三层，并按实测把准入判据改对。

**现在的事实**：标定的「探针唯一命中且 max_error ≤ 1.0 px」这一条对真 VLM **不可达**——模型自身在 2560 宽画面上的定位误差 2.66~4.03 px（M5）、同一张探针五轮真调最大误差 2.14~22.24 px（M6），都大于 1 px；而我们要用 1 px 的探针去分辨 0~999 与 0~1000（右边缘分歧 2.56 px），**信号比噪声小**。结果：视觉通道在生产路径上**恒不可用**（M9 实测 `visual_channel_unavailable`），M14 的 W-1 偏差 30.4/27.1 px，M15 的 CC-1 被准入门拦下、零动作下发。

**三层**：①**标度判定**（探针唯一命中 / 多解——事实，落盘）②**落点等价**（等价标度族内各标度给出的物理落点分歧——事实，落盘）③**准入**（决定）。

**准入判据**：视觉通道可用 ⟺ **能定案**（标度判定唯一 **或** 落点等价）**且** 等价族内最大落点分歧 ≤ **落点容差 2.0 px**（独立常量，与动作越界容差同值但不同语义、不同常量）；存在分歧 > 2.0 px 的替代标度 → 视觉通道不可用（回落 UIA 或报错）。**防线未放松**：2560 宽下 0~999 与 0~1000 的分歧 2.56 px > 2.0 px，仍会被拦下（前提：探针含最右边缘目标）。

**探针分辨力判据**（探针自己分不分得出候选标度）：落点分歧 ≥ **2 × 判定容差** 才算探针能分辨，否则按等价处理（进列表、如实报多解）。**准入不靠它**，它只决定等价列表怎么划。

配套要把**视觉通道的落点精度线按通道分开**：UIA 通道实测 0.0 px（≤2 px），视觉通道实测 2.2~6.7 px（M9 三轮）、crop 精定位中位数 15.03 px（M7）——**「≤2 px」是 UIA 通道的量级，不是视觉通道的**。

## Acceptance criteria

- [ ] 三个容差各归各的、互不共用：判定容差 1.0 px（探针分辨力）、落点容差 2.0 px（等价族分歧）、动作越界容差 2.0 px（动作层）；三者是**三个独立常量**，改一个不影响另外两个（单测逐个断言）。
- [ ] 准入判据按三层实现：等价族内最大落点分歧 ≤ 落点容差 → 视觉通道可用（`available=True`）；存在分歧 > 落点容差的替代标度 → 不可用（`available=False`，理由写清分歧值与替代标度）。**「探针唯一命中」不再是准入的必要条件**——唯一命中必然可用，多解但落点等价也可用。
- [ ] 防线回归：构造「等价族里存在分歧 2.56 px 的替代标度（0~999 vs 0~1000，2560 宽、右边缘）」→ **必须判不可用**（2.56 > 2.0）。再加一条边界用例：分歧恰为 2.0 px → 可用。
- [ ] 探针仍然 2560×1600、4 个目标点、**必须含贴在最右边缘的那个**（n≈1000）；把最右边缘目标去掉 → 准入必须拒绝自己（口径的前提被破坏时不能默默放行）。
- [ ] 真机验证：同一台机器上跑一次标定，**准入判定不再是「恒不可用」**；要么「唯一命中」要么「落点等价（分歧 ≤ 2.0 px）」，两条都要能走到；把等价族人为放大到含分歧 > 2.0 px 的标度 → 正确判不可用。记录真机数字（判定标度、最大误差、等价列表、最大落点分歧、准入结论）。
- [ ] **按通道分开的落点精度线**写进文档与检查项：UIA 通道 ≤2 px（实测 0.0 px）；视觉通道的线按**实测分布**定（用 M7/M9 的现有分布数据给出初值 + 后续怎么重测），**不许沿用 2 px**。两档各自的来源串要落盘。
- [ ] **重跑受影响的三张票的验收**：M6（两级 grounding 分布）、M7（门控与回落）、M9（切视觉红线 + Windows 设置活体测试）——在新的准入判据下重跑，并如实记录哪些结论变了、哪些没变。**不许把旧结论直接搬过来**。
- [ ] 架构决策备忘 §2.6 的 **C-03 检查项已按 2026-10-21 修正改写**（含实测依据：2.66~4.03 px / 2.14~22.24 px / 2.56 px 的关系），`docs/00-现状.md` 的相关段同步；两份文档都留 **dated 注**说明改了什么、为什么。
