## What to build

M23 的留出集重评**没有重新调模型** —— 它建在 M8 已记录的**逐样本 outcome** 上
（`runs/m8-t16/sspro-report.json`）。这留下一个**没被消掉的缺口**：

M23 的 AC 5 要求「两臂**共用同一次模型应答**（应答记忆端口）」，
但 M8 的 `model-requests.jsonl` **不含 prompt / 回答正文**（只有 effort / latency / token 数）
→ **应答记忆端口无法从它重放**。M23 只能用「记录里的逐样本 outcome」离线重建，
再用**重放自检 42/42** 当护栏。

那是**能自证的离线重评**，但**不是**一次真正的留出集评测：阈值挑在 A 半、判定跑在 B 半，
而 **B 半的数仍然来自「A 半那一轮跑批的记录」** —— 换一批新样本重跑，结论可能变。

本单让应答记忆端口**真的可重放**：把 prompt 与回答正文记进请求日志，
于是留出集可以**用真模型重跑** —— A 半挑阈值、B 半评测，**两半都是新跑的**。

## Acceptance criteria

- [ ] **请求日志记下 prompt 与回答正文**：模型请求日志里能读回「这一次的输入是什么、
      模型答了什么」；**大小有上限**（不许把整帧/base64 写进日志 —— 记哈希或路径）。
- [ ] **应答记忆端口能从日志重放**：用记录下来的 prompt / 回答重放，产出与当时
      **逐条相同**的结果（重放自检钉死，不靠「差不多」）。
- [ ] **留出集用真模型重跑**：A 半挑阈值、B 半评测，**两半都是新跑的**
      （不是复用旧跑批的 outcome）；报告写明**重新发了多少条请求**、花了多少。
- [ ] **判据与 M23 一致**：B 上的差值必须**超过噪声量级**才算成立；
      不足 → 判「**不成立**」。报告仍要给出 **A 上的差值（调参过程量）** 与
      **B 上的差值（结论）**两个数，并写明哪个是结论。
- [ ] **可比性体检仍在**：报告落 `coarse_shared` 与 `model_calls.replayed`。
- [ ] **结论不许被这次重跑「洗白」**：重跑结论若仍是「不成立」，**如实保留**；
      若结论翻转，报告里必须写明**与 M23 的差异**与**差异的原因**
      （不许只报新的好数字）。
- [ ] **M23 的结论与报告不被覆盖**：M23 的报告**原样保留**（`docs/reviews/M23.md`
      与它落的那份产物），本单是**另一次**评测，**不改** M23 的结论。
