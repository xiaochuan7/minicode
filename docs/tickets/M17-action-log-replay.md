## What to build

动作日志能完整回放每一步：出事故后能看到「它当时以为自己在干什么」。

日志可导出成机器可读格式，供自己离线统计与回放分析。

日志字段完整且不含敏感内容：只落截图哈希不落原图。

## Acceptance criteria

- [ ] 字段完整：每条记录含时间、动作类型、目标窗口句柄与标题、落点坐标（物理表面空间）、截图哈希、动作前后状态、结果（含错误码）；缺字段即不合格。
- [ ] 可回放：用日志能重放出每一步的动作与结果，且重放结果与当时的记录一致（回放是动作日志层面的可回溯，不是「录一段屏再回放」）。
- [ ] 机器可读导出：导出格式可被脚本解析，且从导出文件能算出成功率、三类失败分布、三段耗时分布（不依赖人工看）。
- [ ] 截图只落哈希：日志与导出里只有截图哈希，没有图像内容。
- [ ] 敏感内容不外泄：日志里不出现密码、密钥等模式的明文（用脱敏器同一套规则检查）。
