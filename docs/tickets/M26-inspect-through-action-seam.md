## What to build

**方向已由人拍板（2026-10-21）**：M19 的「读观察」现在**绕过动作执行缝** —— 它走定点观察端口（`verification.layer.StateObserver` 那个形状），因为协议里的 `inspect` 动作种类**至今未实现**（`action/protocol.py::DEFERRED_KINDS`），而动作执行缝不接它。

这违反了 ADR-0007 的**唯一测试缝**：观察是一条真实的对系统读路径，却**不经过**那条唯一被测的缝 → 它既不产动作记录，也拿不到缝上的闸门（审批、隐私、提权检测）。

本单要做的：把 `inspect` **接线**，让观察走缝。

- `inspect` **已经在 12 个已锁的动作种类里**（M21 锁的是**种类集合**）—— 本单**不新增动作种类**，只把它从「延后」挪到「已接线」。
- 缝接它之后：观察**产动作记录**（含时间、目标窗口句柄与标题、结果），并**经过**缝上的闸门（隐私闸门、审批、提权检测）。
- ⚠️ 观察是**只读**的：不注入任何输入 —— 它归 `OBSERVATION_KINDS`（与 M6 的 `zoom` 同一类：产出一个落点但不注入输入），**不是** `POINT_KINDS`。

## Acceptance criteria

- [ ] `inspect` 变成已接线：`action/protocol.py` 里 `inspect` 从 `DEFERRED_KINDS` 挪到 `EXECUTABLE_KINDS`；**动作种类集合仍是 12 个**（M21 锁的是集合），M21 的锁断言改成与新实现一致（**已接线 / 延后**两个计数随接线变化）。
- [ ] 观察走缝：MCP / HTTP / CLI 的「读观察」改为**发起一个 `inspect` 动作**并由缝执行；`serve/service.py::_observe_controls` 那条**直连观察端口**的旁路**不再存在**（全仓检索断言只有一处能读控件树 —— 缝里的那一处）。
- [ ] 观察产动作记录：读一次观察 → 动作日志里**有一条动作记录**，动作类型 = `inspect`，按动作种类的合格口径（`inspect` **不需要落点**；需要窗口句柄与标题）。
- [ ] 闸门覆盖：观察经过缝上的**隐私闸门**（敏感窗口的控件树**不外泄**）、**审批闸门**与**提权检测** —— 缝上有的，观察也有。
- [ ] 脱敏仍是唯一出口：控件树**只经脱敏器**出去（`redact/redactor.py` 的硬闸门不变）；**脱敏没上线 → 一个字符都不给**（`channel_disabled`），这条断言原样保留。
- [ ] C-09 不破：观察是**定点查询**（必须带名字条件，禁止全树 dump），这条不变；缺 name → `invalid_request`。
- [ ] 动作协议只增不改：协议版本仍是 `cua.action/1`（`PROTOCOL_VERSION` 不动）—— `inspect` 是既有种类被接线，**不是新增种类**。
- [ ] 文档同步：`docs/00-现状.md` 与 `CONTEXT.md` 的「动作记录」「观察」相关词条同步（观察现在是动作，不再是旁路）。
