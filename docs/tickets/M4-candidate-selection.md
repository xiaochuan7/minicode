## What to build

给一句目标描述、一帧截图与一份已脱敏的控件树快照，系统把匹配到的控件候选连同各自的控件框列给模型，模型只在候选集里指出是哪一个、不产生任何坐标。系统据此确定选中项，执行前重读一遍控件树重新定位，取它当前的控件框，把落点定在该框中心后执行点击。

最终落点落在被选中控件的控件框内，与框中心偏差 ≤2 物理像素。候选无法唯一确定时（指不出唯一一项 / 指到候选集之外 / 同时指了多个）系统拒绝执行、不下发任何动作，并把候选集回报给调用方。树里根本没有匹配项、或通道读不出节点时报覆盖失败；候选在但选不出报选择失败——两者分别报出、互不混淆，且只有覆盖失败被标记为允许切视觉。

送模型之前必须已过脱敏；脱敏未上线的状态下这条通道直接拒绝启用。每步回显模型发出的内容（选中项 + 控件框）与实际发送的图片尺寸；候选集与选中项写进追踪记录的旁路出口，不进主返回类型。

口径说明（需同步修订规格）：**候选不唯一时先做消歧**——在 UIA 候选集内让模型**只做指认**（候选唯一时零模型调用；指认必须落在候选集内且恰好一个）。消歧失败、**候选数超过上限**（默认 8）、或指认不唯一 → 走 L4 错误处理。**任何情况下都不切视觉。** 这与规格 user story「同名控件有多个候选时拒绝执行并把候选报给我」的字面表述不同，实施时须同步修订规格与相关决策记录，使文档与实现不再互斥。

## Acceptance criteria

- [ ] 命中落点：假树给一个候选（控件框 (100,200,180,240)，物理像素），模型指认它 → 动作执行缝输出的动作是点击，最终落点 = 重读后该控件框中心 (140,220)，落在该控件框内，与框中心偏差 ≤2 px；假输入注入收到的就是这组物理表面空间坐标。
- [ ] 模型坐标不参与：假模型响应额外带 x/y 字段（如 1234/5678）→ 落点仍是控件框中心而不是 (1234,5678)；捕获到的模型请求里只有「从候选清单里选哪一个」这一项任务，没有任何要求输出坐标的措辞，请求体里也没有任何坐标换算提示。
- [ ] 唯一性拒绝的返回形态：两个同名候选 + 模型未给出唯一指认（返回空 / 返回候选集外的 id / 同时指两个）→ 返回选择失败（唯一性拒绝），错误载荷里能读到控件候选集（每项的标识、名字、控件框）与失败原因。
- [ ] 候选数上限可判定：候选集大小超过上限（默认 8）时不调模型（模型调用计数 = 0）、直接走 L4 错误处理并回报候选集；上限是运行时参数，取值来源被记录。
- [ ] 拒绝时零动作：同一输入下，假输入注入的调用序列为空（无移动、无按下、无抬起），且不产生任何动作意图。
- [ ] 失败分类可辨：候选集为空（树 0 节点 / 目标不在树里）→ 报覆盖失败；候选非空但选不出 → 报选择失败；两者标识不同、互不混淆，且只有覆盖失败被标记为允许切视觉（选择失败不得触发切视觉）。
- [ ] 脱敏闸门：脱敏器未上线（或拿不到脱敏后的树）→ 该通道被拒绝启用（返回明确错误，如「脱敏未上线，禁止把控件树送模型」），且模型调用计数 = 0。
- [ ] 执行前重读重定位：第一次观测有该候选、重读时树里已没有它 → 零动作 + 报「重读定位失败」；重读时该控件框已移动 → 落点用新框（旧框不命中新框）；重定位不得用上一次观测的元素 id，必须用跨观测稳定的条件（AutomationId / runtime id / 名字 + 控件类型）。
- [ ] 追踪记录 + 每步回显：注入的旁路出口里能读到控件候选集与选中项；主返回类型仍只含「动作 + 最终落点 + 意图」，不含任何追踪字段；每步回显里能读到「模型发出的选择结果 + 实际发送的图片尺寸（宽×高）」，且回显里没有坐标（本单模型不产坐标，不许伪造成坐标回显）。
- [ ] 文档同步：规格里「唯一性拒绝 / 消歧」的相关表述、架构备忘对应里程碑条目与相关决策记录的一致性修订已落地，文档与实现不再互斥。
- [ ] 本单不实现切视觉：只负责把覆盖失败与选择失败分清、只给覆盖失败打「允许切视觉」的标记；切视觉本身由另一张单实现。
