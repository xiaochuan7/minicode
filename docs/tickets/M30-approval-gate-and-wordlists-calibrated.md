## What to build

把审批与词表这一摊收口：

- **评测台接审批闸门**（D-29）：现在真机端到端评测**不受审批保护**，危险动作在评测台里能直接跑
- **十一类关键词表按真实日志校一遍**（D-30）+ **敏感词表按真实日志校一遍**（D-43，同源）：两张表现在都是「工程阈值·未验证」
- **词表可配**（D-12）：用户能加自己的不可逆词/危险词，**默认值仍然写死**（安全默认不变）
- **输入文本的 dry-run 拿得到目标**（D-27）：审批请求要绑定「意图 + 目标」，但输入文本现在没有目标 → 给「窗口标题 + 焦点控件」
- **删掉 M12 的 `DangerGate`**（D-28）：它已被 M16 的十一类清单取代，留着就是两份判据并存
- **剪贴板口径同步**（D-26）：粘贴通道的**备份读不算**「读剪贴板」（备份读完原地写回，从不进模型）——**M20 的 AC2 要同步改**（两票现在说两套）

## Acceptance criteria

- [ ] **评测台接闸门**：真机端到端评测走同一套审批闸门（fail-closed：没接审批人 = 危险动作一律没批、零动作下发）；单测断言评测台与生产走的是**同一个闸门实现**。
- [ ] **两张词表按真实日志校**：十一类关键词表与敏感词表用**真实动作日志**跑一遍，报出误报率与漏报样本；校完的词表**标注来源**（不再是「工程阈值·未验证」），并保留原始值。
- [ ] **词表可配但默认值写死**：能加载用户自定义的补充词表（追加，不覆盖默认）；**不提供配置时行为与现在完全一样**。
- [ ] **输入文本的 dry-run 有目标**：文本类危险动作的审批请求带**窗口标题 + 焦点控件**（能定位到具体控件/窗口），不再是「没有目标」。
- [ ] **M12 的 DangerGate 删干净**：代码里**搜不到** `DangerGate` 这个判据（单测扫源码把住）；十一类清单与 M12 不可逆词表的**子集关系**仍然成立（M12 的词表是 M16 清单的子集）——单测保住这条关系。
- [ ] **剪贴板口径两处一致**：M20 的 AC2 改成「**读剪贴板内容**要审批；粘贴通道的备份读不算」；实现与 M16 的 AC 措辞**逐字一致**（不许一张票说一套）。
- [ ] 校准过程可复核：报告里给出校准用的日志样本量、误报/漏报的具体样本。
