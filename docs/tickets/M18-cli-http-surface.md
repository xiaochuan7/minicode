## What to build

桌面控制既能作为独立命令行工具运行，也能在脚本与服务里通过 HTTP 被调用。动作协议版本化，换前端或换宿主时动作语义不变。

两条入口走同一套动作协议与坐标口径，不各自实现一遍。

## Acceptance criteria

- [ ] CLI 可用：命令行能发起一次动作、读回结果与动作日志；退出码能区分成功与失败。
- [ ] HTTP 可用：HTTP 接口能发起一次动作、读回结果；错误码与协议里的取值一致。
- [ ] 语义一致：同一条请求经 CLI 与 HTTP 得到相同的动作与落点（同一入口实现，不是两份）。
- [ ] 协议版本化：协议带版本号；版本不匹配时明确报错，而不是按旧语义猜。
