## What to build

M8 的门控结论是**在同一批样本上调参数得到的**：一致性容差从 128 px 调到 16 px 之后，「门控开 59.5% ≥ 门控关 57.1%」成立（+2.4 pp）。**同批调参 + 同批评估 = 过拟合**，该结论不成立于新样本。

M8 自己记下的证据也说明它站不住：两臂虽然已共用同一次粗定位/整屏第二遍/精定位回答（应答记忆端口），仍有 **35/42 条**两臂的粗定位点不同（最大差 3062 px）、**11 条**命中与否翻转，**噪声量级与要测的效应同量级**——而要测的效应只有 +2.4 pp。

本单把 C-16 的判定改成**留出集**判定：阈值在样本 A 上调，结论只在样本 B 上成立；并给出「差值必须超过噪声量级」的判据。

## Acceptance criteria

- [ ] **样本切分固定且可复核**：按 ScreenSpot-Pro 的样本 ID 把本单使用的样本切成 **A（调参）/ B（评估）** 两半；切分规则写进代码（不是手挑），并把每条样本属于哪一半落进报告。切分后两半的样本数与关键统计（目标占比分布等）都要写进报告。
- [ ] 门控阈值**只在 A 上调**（一致性容差、目标占比分位、置信度阈值、偏离容差——凡是运行时要调的都在 A 上调）；**B 上不许再调任何参数**。
- [ ] **AC2 判据改为「在 B 上，门控开 ≥ 门控关」**；同时报告必须给出「A 上的差值」与「B 上的差值」两个数，并明确写出 **B 上的差值是结论**、A 上的差值只是调参过程量。
- [ ] **差值必须超过噪声量级**才算成立：报告给出同批样本上的**翻转条数**与「两臂粗定位点不同」的比例作为噪声量级；**B 上的差值 ≤ 噪声量级 → 判「不成立」**，不许只报一个百分比就下结论。
- [ ] 沿用 M8 已经做对的那两条，不许退回去：两臂**共用同一次模型应答**（应答记忆端口），并把 `coarse_shared` 与 `model_calls.replayed` 作为可比性体检落进报告。
- [ ] 门控关闭率也报（B 上），且**门控关闭率 > 0** 这条判据（AC3）同样在 B 上判。
- [ ] **M8 的原结论作废并留痕**：M8 的 reports 与 `docs/reviews/M8.md` 里那组「同批调参后 59.5% ≥ 57.1%」的数字**必须标注为「不可作结论」**并指向本单的留出集结果；不许把旧数字留在没有标注的地方。
- [ ] 门控参数（一致性容差 128 px、偏离容差等）的**来源串**按 M7 的口径随判定落盘：实测校准过的写清楚，**没校准的写「工程阈值·未验证」**，不许写成已验证结论。
