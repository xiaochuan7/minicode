## What to build

两条都能演示的行为：

第一，Windows 设置（XAML island，本机实测所有相关窗口的控件树元素总数为 0）上走通纯视觉定位并点中一个已知目标，落点误差 ≤ **该通道的落点精度线**（视觉通道本机三轮实测 2.2~6.7 px；**≤2 物理像素是 UIA 通道的量级**，见 M22）——这是视觉兜底层的活体测试，这条应用通过才说明视觉通道不是纸面能力。

第二，切视觉的红线可判定：UIA 通道产不出任何候选（覆盖失败）才允许切视觉；候选不唯一、被遮挡、尺寸异常、查询超时、名称匹配不上——这些一律禁止切视觉，必须走校验与纠错层的错误处理。否则「切视觉」会从罕见事件退化成每步都付 1.5~5 秒，架构优势全丢。

标定失败即视觉通道不可用：回落 UIA 通道或直接报错，不猜一个标度继续跑。UIA 命中时零模型调用（亚秒级、零成本），且这一点可被证明。能力表里 Windows 设置**按进程逐条**记（一个进程不可用、另一个部分覆盖），不是「UWP 一律可用」，且「部分覆盖」这一态在表里必须真的存在。覆盖失败 / 选择失败 / 执行失败 / 通道级失败 / 决策失败五值分开报。抓屏拿到 0×0 画面时跳过该捕获源，不点虚空。

## Acceptance criteria

- [ ] Windows 设置上的纯视觉命中：控件树实测为 0 节点时，系统判「覆盖失败」并切视觉通道；在该应用里点中一个已知目标，落点与该目标中心的偏差 ≤ **该通道的落点精度线**；追踪记录里通道 = 视觉通道、失败类型 = 覆盖失败（不是「目标不存在」）。
  > **2026-10-21 实测修正**：原 AC 字面是「≤2 物理像素」——那是 **UIA 通道**的量级（UIA 落点直接取控件框中心，实测 0.0 px）；**视觉通道**本机三轮实测 2.2 / 6.7 / 6.1 px，沿用 2 px 会让本条**永远不成立**。两条通道的线分开定（视觉通道的线按实测分布定，见 M22）。
- [ ] 切视觉只认覆盖失败：预置四种非覆盖失败场景（候选不唯一（先做消歧）/ 候选被遮挡 / 候选尺寸异常 / 查询超时）——每一种都必须走错误处理，且视觉通道的调用次数为 0、动作按错误处理的规定处置（不静默重试、不落到别处）。**「名称匹配不上」按「候选集空不空」判**：条件查询**找到了候选**但没有一个与描述对得上 → **选择失败**（禁止切视觉）；条件查询**一个都没找到** → **覆盖失败**（允许切视觉；含 0 节点 = 通道产不出候选）。
  > **2026-10-21 实测修正**：原 AC 把「名称匹配不上」与前四种并列成「一律禁止切视觉」，与「条件查询带条件仍找不到 = 覆盖失败」的口径冲突（条件查询本来就是带条件找的）。已统一为「候选集空不空」是判据（与 M4 的口径一致）。
- [ ] UIA 命中时零模型调用：同一次运行里对树可用的目标执行动作，模型调用计数为 0、端到端延迟 ≤1 s（亚秒级），且该结论可被计数证明而不是靠约定。
- [ ] 标定失败即视觉通道不可用：把标定结果构造成不唯一或失败 → 视觉通道准入被拒，系统回落 UIA 通道（若在）或报明确错误码；不猜标度继续跑。
- [ ] 能力表：Windows 设置**按进程逐条**按实测填（本机实测：`SystemSettings.exe` = 不可用（树 0 节点）、`ApplicationFrameHost.exe` = 部分覆盖（树在、138 个元素）——**一个应用对应两条，不合成一条**）；表里三态都真的存在；不得出现「UWP 一律可用」「Chromium 一律失效」这类类别级结论。
  > **2026-10-21 实测修正**：原 AC 字面是「Windows 设置这一条 = 不可用」，与本机实测不符——该应用在能力表里有**两个条目**（两个进程），其中一个是部分覆盖。能力表的键是「应用 + 版本」（M3 的 AC 已这么定），**一条应用可以对应多条**。
- [ ] 抓屏 0×0：抓屏拿到 0×0 画面时跳过该捕获源（不点虚空），并把该捕获源标记为不可用；此时动作不产生落点。
- [ ] 失败类型分开报：**五值** —— 覆盖失败 / 选择失败 / 执行失败 / 通道级失败 / 决策失败，标识不同、互不混淆；每一步的追踪记录里能读到本次走的通道与失败类型。
  > **2026-10-21 实测修正**：原 AC 字面写「三类」。**查询超时**塞进「覆盖失败」或「选择失败」都不成立（既不知道目标在不在树里，也压根没有候选），**决策失败**是 `CONTEXT.md` 的既有概念 → 五值。
  > ⚠️ 这五值是**定位轴**；`CONTEXT.md` 的「三类失败」（定位 / 决策 / 执行）是**埋点轴**，两套**正交**，不要混用。
