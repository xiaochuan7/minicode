## What to build

视觉通道每次启用之前，系统先用一张与本机物理表面同尺寸的合成标定探针图向模型索要四个已知目标的坐标，据此判定模型输出实际使用的量纲——五种标度（0~1 / 0~999 / 0~1000 / 截图像素绝对 / 模型输入像素绝对）里判哪一个成立。判出来的分母从此是坐标换算链路的唯一真值来源：代码里不出现写死的 1000 或 999，也不用数值大小去猜量纲。

标定容差固定 1.0 px，与动作协议的 2 px 越界容差是两个互不共用的常量。探针把目标贴到画面右缘，使 0~999 与 0~1000 在该点上的落点分歧达到 x 轴 2.4 px / 欧氏 2.86 px，在 1 px 判定容差下留 2 倍以上余量。

标定唯一性不成立或标定失败时，系统拒绝走视觉通道——回落 UIA 通道或直接报明确错误——而不是猜一个标度继续跑。每次标定留下一条可读回的记录（标定时间、探针图哈希、判定标度、判定容差、各候选最大误差、等价标度列表、唯一性标志、模型标识、调用路径），事后能复盘「当时按哪个量纲算的」。

同一个模型的文本调用与图像调用各标定一次，两条坐标路径的分母各自独立，不会有一条悄悄走错。

口径说明（实施时按此写死）：**落点等价判据**——标定探针给出候选标度族；只有在**存在使物理落点分歧 > 标定容差（1 px）的替代标度**时，视觉通道才不可用。分歧 ≤ 容差的等价标度族**允许继续**（等价列表必须落盘），但**标度判定**如实记为**多解**。**前提**：探针必须含最右边缘目标——0~999 与 0~1000 的物理分歧随 x 线性增长、最大值在右边缘，探针不覆盖最坏情况则本判据悄悄失效。理由：模型输入像素空间的尺寸等于截图像素空间的尺寸时，两种绝对标度落点完全相同，若按「多解即拒绝」字面执行会把视觉通道永久判死。

## Acceptance criteria

- [ ] 探针几何：标定探针图尺寸 == 本机物理表面尺寸（本机 2560×1600），源码中不存在 1280×720 的探针默认值；四个目标中至少一个真值 x ≥ 0.95×探针宽；该点上 0~999 与 0~1000 的落点分歧 x 轴 ≥ 2.0 px、欧氏 ≥ 2.5 px，即在 1.0 px 标定容差下余量 ≥ 2 倍。
- [ ] 静默失败可测出来（两条必须以单测形式存在）：把判定容差改成 2.0 px（探针仍 2560 宽）→ 0~999 必被判进等价标度列表；把探针缩到 1280 宽（容差仍 1.0）→ 0~999/0~1000 必判为等价。两条断言均为「等价列表含 0~999」；不满足即判不合格（等于标定会静默选错标度）。
- [ ] 两个容差互不共用：标定容差 == 1.0 px、越界容差 == 2.0 px，命名与定义各自独立；存在两条独立性断言——改标定容差不改变越界判定结果，改越界容差不改变标定判定结果。
- [ ] 五种标度全部可判：桩模型分别以五种标度作答时，判定标度与桩一致 5/5，且五个候选各自的最大误差被记录。
- [ ] 标度判定与落点等价必须分开报：模型输入像素空间的尺寸 == 截图像素空间的尺寸时，两种绝对标度同入等价标度列表，**标度判定如实记为「多解」**并给出等价列表；任何情况下都不得在等价情形下报告「唯一命中」。同时给出**落点等价**结论（容差内等价 / 分歧）——两个维度不许混成一个字段。
- [ ] 越界记为无穷大误差、不中断：把 0~1000 的数值（如 953）当 0~1 解释时，该候选最大误差 == 无穷大（不是抛异常、不是流程中断），标定仍跑完并给出其余四个候选的误差；越界判定先在模型空间做出。
- [ ] 硬闸门（落点等价判据）：**存在使物理落点分歧 > 标定容差（1 px）的替代标度**时，视觉通道准入判定返回「视觉通道不可用」并拒绝产出任何视觉通道落点；请求改走非视觉通道分支（UIA 通道在则回落，否则报明确错误码）；追踪记录带「视觉通道不可用」标记，走旁路出口、不进主返回类型。**标度判定为多解、但各等价标度族的落点分歧都在容差内**时：视觉通道**允许继续**，追踪记录标记「落点等价」并附等价列表，**不标记**通道不可用。
- [ ] 落盘：每次标定产出可离线读回的一条记录，含标定时间、探针图哈希、探针尺寸、判定标度、标定容差、各候选标度与最大误差、等价标度列表、**标度判定（唯一命中 / 多解）与落点等价（容差内等价 / 分歧）两个字段**、模型标识、调用路径；只落探针图哈希、不落原图；能从记录复原「当时按哪个量纲算的」。
- [ ] 两条调用路径各一次：同一模型上真调一次，文本调用与图像调用各产出一份标定记录，两份记录各自独立存储、互不覆盖；任一路径无记录或标定失败时，该路径不得借用另一路径的标度。若真机上单点误差大于 1.0 px 导致标定失败，必须如实记为标定失败（视觉通道不可用），不得为让它通过而放宽判定容差。
- [ ] 无写死分母、无按大小猜量纲：除标度枚举与其名义分母定义表外，换算/标定链路其他位置不出现 1000 / 999 字面量；换算适配器没有默认标度（标度必须显式来自标定结果）；不存在按数值大小选量纲的分支（喂入 0~1000 的 953，适配器不会自动改判为绝对像素标度）。
- [ ] 只依赖标准库：探针图的生成与 PNG 编码只用标准库实现，本单不因探针引入第三方包；第三方依赖只允许作为可选附加项。

## Blocked by

- M0 — 最小闭环（探针尺寸的唯一真值来源是 DPI 感知后的物理表面度量与启动自检断言；否则探针尺寸会变成第二份真值）
- M1 — 模型客户端（标定必须经客户端真调，并取「实际发出的那张图的宽高」作为绝对像素候选的基准；否则没有可落盘的真值）
