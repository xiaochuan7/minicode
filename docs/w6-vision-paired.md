# W6 视觉坐标契约配对实验（ScreenSpot-Pro）

生成时间：2026-11-02 01:23；生成器：`scripts/make_w6_report.py`（从配对 JSON 如实转写，可复现）。

## 模型身份（如实披露）

* **model id**：`deepseek-v4.1-flash`；**端点**：`https://opencode.ai/zen/go/v1/chat/completions`（OpenAI 兼容 `/chat/completions`；密钥在仓库外 .env，不入库）。
* **采样参数**：推理档位 effort=`low`（仓库端点的档位选择），输出预算 max_tokens=8192，温度等未传即服务端默认。
* **提示词**：生产粗定位提示词（`ground/prompt.py::coarse_prompt`）逐字——两臂**唯一差异**是坐标声明一行（臂 A「坐标是这张图的像素」→ 臂 B「坐标是 0~1000 的归一化坐标」）；其余逐字相同。

## 数据与判定口径

* 数据集：ScreenSpot-Pro（likaixin/ScreenSpot-Pro，经 hf-mirror 下载，存于仓库外）（MIT，非 gated；本地存于仓库外目录，本仓库不含任何图片）。
* 样本：60 条（每层 10、seed=20251020，`stratified_subset` 确定性抽样）。
* 判定：官方口径——落点落在 GT bbox 内（Surface 空间，等比缩放下与归一化判定等价）。**两臂同一判定**。
* 设计：同一张缩放后的模型输入图、同一模型、同一采样参数，逐条配对；**本报告不拿单臂绝对分当结论**——单臂数字只用于配对上下文。

## 结果（配对）

| 臂 | 命中 | 命中率 | Wilson 95% CI |
|---|---|---|---|
| pixel（现状） | 13/60 | 21.67% | [13.12%, 33.62%] |
| 0-1000 归一化 | 7/60 | 11.67% | [5.77%, 22.18%] |

* **2×2 配对表**（n=60）：双中 6 · 仅 pixel 中 7 · 仅 0-1000 中 1 · 双不中 46。
* **Δ**（0-1000 − pixel）：**-10.00 百分点**，配对 bootstrap 95% CI -18.33 ~ -1.67 百分点（不含 0）。
* **mid-p McNemar（主报）**：p = 0.0391（保守对照：exact p = 0.0703，χ²+Yates p = 0.0771）。
* 不一致对占比（噪声地板）π̂_d = 0.133；本样本量 MDE ≈ 13.2 百分点（|Δ| 未达 MDE——**样本量不够**下结论，不是「没差异」）。

## 诚实注记

* 调用错误：pixel 臂 12 条、0-1000 臂 8 条（计入未命中方向，明细在配对 JSON 的 outcomes 里）。错误构成：NoTextOutputError×20
* 结论强度：|Δ| 未达本样本量的 MDE，且保守对照（exact / χ²+Yates）未过 0.05——这是**方向性证据**（与 mid-p 主报同向），不是定论；要定论需加大样本。
* **单级对比**：只比整屏粗定位那一级；两级路径里 crop 精定位的坐标语言是另一个实验，未混入。配对 JSON 里 `strata.coarse_hit/coarse_miss` 为空是预期行为（本实验没有粗定位臂可分层）。
* 两臂各按其**声明的契约**解释回答；未做逐尺寸标定探针（生产行为的标定是另一条线，此前已有记录）。
* 原始样本与逐条回答落在 `runs/w6/`（gitignored，仓库外图片不出库）；**配对 JSON 已入库**为 `docs/w6-paired.json`。
